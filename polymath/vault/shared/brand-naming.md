# Abundenz — Brand Naming System

## Hierarchy

```
Polymath          Empire (internal, never public)
 └─ Abundenz      Brand moniker (public parent brand)
     └─ [Ecosystem Sub-brand]    Each ecosystem gets a name from its own category
         └─ [Vertical Sub-brand]  Each vertical gets a name from the ecosystem's category
```

## The Z Rule

Every sub-brand name contains a **z** — replacing a letter, preferably near the end. This is the Abundenz signature. The z signals membership in the Abundenz family without needing to spell it out.

Examples: Socratez, Chartreuz, Catalyzt, Florenz, Prizmz

---

## Category Brainstorm

Each ecosystem gets ONE category. Verticals within that ecosystem draw names from that category's pool. Categories should be:
- Esoteric, eccentric, fun
- Single memorable words
- Scalable (50+ names in the pool)
- Thematically connected to the ecosystem's purpose
- Apolitical but progressive
- NOT: animals, foods, generic tech terms

## Naming Rules

1. Every sub-brand contains at least one **z**
2. Prefer replacing the last letter or a consonant near the end
3. If the word already contains a z (Spinoza, Azimuth, Zeugma), keep it — bonus points
4. Keep it to one memorable word (no "Abundenz Catalyzt Tech" — just "Catalyzt")
5. The Abundenz parent brand is implied, not always stated
6. Each ecosystem owns its category exclusively — no cross-pollination
7. Document every name assignment in this file to prevent collisions
8. Check for trademark conflicts before public use of any name
