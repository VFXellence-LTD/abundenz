# Signal — Banned Topics

These topics are off-limits for Signal content. No exceptions without explicit review and decision to update this document.

---

## Hard Bans (never, under any circumstances)

### Beginner coding tutorials
**Why banned:** Signal's audience writes Python. "Variables and loops" content insults the audience and attracts the wrong viewers who will not convert to any paid product. Signal starts at intermediate Python — not "what is a function."

**Edge cases:**
- Explaining a specific Python pattern used in pipeline context (e.g., context managers for DCC state management) = allowed
- "Python for beginners" framing, "Python basics" titles = banned

---

### "How to break into VFX" career advice
**Why banned:** Generic, saturated, not Signal's domain. The audience is already in VFX. Career ladder content for people outside the industry attracts a non-paying, non-converting audience. Not the niche.

**Edge cases:**
- "How to become a pipeline TD from a generalist role" with technical specifics = borderline, skip
- "What skills does a pipeline TD need in 2025" = allowed only if technical and specific, not motivational

---

### Vendor-sponsored content disguised as reviews
**Why banned:** Destroys trust permanently. The entire value proposition of Signal reviews is that they're independent. One undisclosed sponsor deal eliminates the credibility.

**Policy:**
- Sponsored content is allowed ONLY with explicit, prominent disclosure at top of video/post
- Disclosure must name the sponsor and state "this video was sponsored by [Sponsor]"
- Sponsored content cannot be a tool review — reviews are always independent
- Sponsored content can be: "I'm building a workflow demo using [Sponsor's tool] — they sponsored this video"
- No "thank you to our partner" language that obscures the commercial relationship

---

### AI art generation techniques
**Why banned:** Brand isolation. Generative AI art is Atelier's domain. Signal and Atelier are separate brands with separate audiences. Cross-contamination dilutes both brands and breaks audience trust on both sides.

**Specific bans:**
- Stable Diffusion, Midjourney, DALL-E, Flux, ComfyUI for image generation
- AI video generation (Sora, Runway, Kling) as primary topics
- "How VFX artists can use AI art tools" framing

**Allowed:**
- AI-assisted pipeline tooling (monitoring, QC, automation) = Signal's Pillar 6
- AI code generation for pipeline scripts = allowed
- Discussing AI's impact on VFX industry at high level, once, briefly, as context

---

### Halon Studios' proprietary pipeline details
**Why banned:** Employer IP. Halon Studios' internal pipeline architecture, custom tools, client names, project details, and studio-specific configurations are confidential.

**What this means in practice:**
- Can't share actual production tool configs from Halon projects
- Can't name Halon clients or projects as context for content
- Can demonstrate concepts using constructed examples that happen to match real patterns
- "At a studio I've worked with" = fine. "At Halon Studios" = not fine without explicit approval.

**Permitted:**
- General patterns observed across studios (not attributed to Halon)
- Open-source tools and public configurations
- Demo projects built specifically for content creation

---

### Political and social commentary
**Why banned:** Not relevant to the audience, not Signal's domain, creates brand risk without upside.

**Specific bans:**
- Political party affiliation or electoral content
- Social justice framing unrelated to the industry
- Geopolitical commentary

**Edge cases (allowed):**
- VFX industry labor issues (strikes, credits, residuals) when directly relevant to a pipeline or ops topic = allowed carefully
- Remote work / studio location policy = allowed as practical context
- Diversity in VFX as an observation, not a campaign = acceptable once, briefly

---

### "AI will steal your job" fearmongering
**Why banned:** Clickbait that generates anxiety without information. Not Signal's tone. The audience is experienced enough to have their own view — they don't need manufactured anxiety.

**Anti-pattern titles never used:**
- "AI is going to replace pipeline TDs (here's how to survive)"
- "Is your job safe? AI and VFX pipelines"
- "The pipeline skills AI can't replace (yet)"

**Allowed framing:**
- "Here's what AI-assisted tools actually do in a pipeline today" (practical, factual)
- "I automated X with an LLM — here's the code and where it failed" (engineering, honest)

---

### Salary and compensation discussions
**Why banned:** Legal liability. In some jurisdictions, public salary discussions can create employer obligations. Not Signal's domain. Audience doesn't need Signal for this — Glassdoor and VES surveys exist.

**Specific bans:**
- "What does a pipeline TD make in [city]"
- Salary negotiation advice
- Rate recommendations for freelance pipeline work

**Allowed:**
- "Pipeline tools at this price point" = fine (product cost, not salary)
- "Cloud render cost for a small studio" = fine (business cost, not salary)

---

## Soft Bans (requires justification to include)

### Game dev pipeline content
Not the niche. Some overlap (USD, Python, Unreal), but game dev pipeline has its own ecosystem and audience. If content is genuinely cross-applicable to VFX, it's allowed with VFX framing.

### Post-production operations outside VFX
Broadcast, advertising, corporate video — different workflows, different tools, different audience. Signal stays VFX.

### Generic DevOps without VFX context
Docker, Kubernetes, CI/CD — allowed only when applied specifically to VFX pipeline problems. "Docker for pipeline teams" = fine. "Docker for developers" = not Signal.

### Animation-only pipeline content
Feature animation and VFX overlap but diverge. Animation pipeline (rigging, scene management, animation caching) is adjacent — include only when directly relevant to VFX shots pipeline.

### Business/entrepreneurship content
Signal is not a business podcast. Occasional meta-content about running a pipeline-as-a-service or building a consulting practice is borderline — only if it's grounded in technical context.

## Topic Review Process

When a proposed topic feels borderline:
1. Check which ban category it might violate
2. Check if it serves Persona 1-4 (see [[brief/niche]])
3. Check if it fits a content pillar (see [[brief/niche]])
4. If still unclear: default to skip. Signal's value is focus, not breadth.
