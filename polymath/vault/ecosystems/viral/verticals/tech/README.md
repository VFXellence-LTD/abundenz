## Content rules (extends safeguards/POLICY.md)

- All content labeled as AI-assisted per platform requirements
- No false claims about tool capabilities
- No financial advice (even when covering fintech tools)
- Disclose affiliate relationships per FTC requirements
- Never claim personal use of tools you haven't tested
- No deepfakes or impersonation of real people

## Production pipeline

```
1. SOURCE    Scan Product Hunt / HN / TikTok Shop trending (10 min)
2. SCRIPT    Claude generates script from tool + hook template (2 min)
3. RECORD    Screen record tool demo with OBS (10 min)
4. VOICE     ElevenLabs AI voiceover from script (2 min)
5. EDIT      CapCut — overlay text, transitions, captions (10 min)
6. POST      TikTok first → cross-post YT Shorts → IG Reels (5 min)
7. LINK      Update link tree if new affiliate product featured (2 min)
```

Total per video: ~40 minutes. Target: 2-3/day = 1.5-2 hours.
