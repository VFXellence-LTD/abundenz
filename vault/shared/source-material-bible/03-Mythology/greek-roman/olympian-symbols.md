# Olympian Symbols (Quick-Reference Set)

> One clean icon per god: a ready-made, public-domain symbol system for icon packs, patterns, quizzes, and minimalist deity branding.

## Who / What
This is a consolidated quick-reference of the single most recognizable attribute-symbol for each major Olympian, designed as a reusable icon system rather than a character study. Each god in Greek myth is associated with a small set of attributes; reduced to one clean icon each, they form a coherent, instantly readable symbol set — perfect for sticker packs, repeat patterns, "which god are you" quizzes, and minimalist apparel lines. All of these symbols are ancient and public domain.
