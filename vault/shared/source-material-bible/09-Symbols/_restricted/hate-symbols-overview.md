# Hate Symbols — DO NOT USE (Overview)

> The do-not-use set. These entries exist so the pipeline can recognize and reject hate-associated symbols — never to deploy them.

## Doctrine

Hate symbols are **never used commercially**, even when ancient and benign in origin. Public-domain-by-age does **not** clear a hate association. The safe failure mode is "don't use it."

The authoritative reference is the **[ADL Hate on Display™ Hate Symbols Database](https://www.adl.org/resources/hate-symbols/search)**. Before using any symbol with a possible extremist secondary meaning — especially Norse/runic, Germanic, numeric-code, or Celtic-cross imagery — screen it against the ADL database.

## Context rule

Per the ADL, **few symbols represent only one idea or are used exclusively by one group** — every symbol must be evaluated in the context in which it appears. A single Norse rune in a scholarly Futhark chart is not the same as the same rune isolated in militaristic/Germanic-nationalist styling. When context is ambiguous, **default to avoid**.

## Flagged sets documented here

- **Swastika** — see [[swastika-warning]]. Ancient/PD and still sacred in Hinduism, Buddhism, Jainism; but in Western commercial contexts it is overwhelmingly read as the Nazi Hakenkreuz. Avoid commercially.
- **SS bolts (doubled Sowilo)** — see [[ss-runes-warning]]. Banned in Germany/Austria.
- **Appropriated runes** (Othala, Tiwaz/Tyr, Algiz/"life rune", Wolfsangel, Odal-with-serifs) — see [[runes-hate-appropriation-warning]].
- **Numeric codes** (e.g. 14, 88, 1488, 18, 311) and coded acronyms — flagged by the ADL; avoid using these numbers as standalone "design" elements in extremist-adjacent styling.

## Bottom line

**Recognize and reject. Never deploy. Screen against the ADL database. Default to avoid.**
