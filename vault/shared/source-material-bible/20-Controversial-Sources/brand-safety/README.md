# Brand Safety — Niche Isolation & Operating Guides

This subfolder contains the practical operating playbooks for running controversial niches as a commercial business. It bridges the legal doctrine in the other subfolders with executable business decisions.

The organizing principle across all files here is **brand isolation**: any niche with elevated legal, platform, or reputational risk should run under a dedicated brand, not the main VFXellence/Polymath storefront.

---

## The isolation brand

Throughout this subfolder and section 20, the placeholder `<ISOLATION-BRAND-TBD>` marks every location where the dedicated isolation brand's name would go. This brand does not yet have a name. **Boss must decide the name before the brand is launched.** The structure, policies, and playbooks are documented here so that when the name is chosen, execution can begin immediately.
