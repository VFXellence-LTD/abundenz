# Four Elements (Sticker Pack)

> A five-sticker set — Fire, Water, Air, Earth, Spirit — each a classical alchemical glyph framed in sacred-geometry linework, in ink-and-gold. The esoteric/occult sticker staple. This file holds **five sub-recipes** sharing one formula.

A **symbol-led** [[master-formula]] application where the glyph *is* the product. Because all five share a formula, this is a single file with five catalogued variants.

## The shared formula

`[Alchemical Glyph] + [Optional Animal] + [Ink/Gold Palette] + [Esoteric Serif] + [Element Word] = element sticker`

| Slot | Accepts | Draws from |
|------|---------|-----------|
| 1 Glyph | classical element triangle, alchemical sign, ouroboros | [[09-Symbols/README]] (alchemical/elemental) |
| 2 Animal *(optional)* | salamander (fire), fish (water), bird (air), serpent (earth) | [[line-art-animals]] |
| 3 Palette | [[monocrome-ink]] (+ gold) | [[08-Color-Palettes/README]] |
| 4 Type | thin esoteric serif | [[07-Historical-Design/typography]] |
| 5 Word | element name / short Latin | coined / [[12-Quotes/README]] |

Shared product spec: **die-cut vinyl stickers**, ~3" each, CMYK (or ink + gold-foil). Sacred-geometry ring frames each glyph. Sell as a 5-pack.

## Legal guardrails

**Never** copy a brand's stylized flame/element logo; keep all glyphs in their plain classical geometric form and any animal a real species.

- [[fire]] / elemental glyphs — classical triangles are free; avoid stylized brand flame marks.
- [[ouroboros]] — design your own coil; don't copy a named artist's/game's specific ouroboros.
- [[line-art-animals]] — generic real species.
