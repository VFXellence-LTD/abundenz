# Apps Ecosystem (Forge)

Cross-platform apps (Windows, iOS, Android) with freemium monetization. Small utility apps solving specific pain points.

## Model
- Build small, focused apps — one core feature each
- Freemium: free base, paid unlock for premium features
- Cross-platform where possible (React Native, Flutter, or Tauri)
- Publish under VFXellence Ltd on all stores

## Revenue Streams
- In-app purchases (feature unlock)
- Subscriptions (premium tier)
- One-time purchases
- Ad-supported free tier (optional, per-app decision)

## Brand
- Part of Abundenz family
- Z-naming convention applies
- Each app gets its own name/brand (not "Abundenz [App]")
