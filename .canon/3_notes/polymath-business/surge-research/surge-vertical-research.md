### Winner: Tech / AI Tools

**Why it scores highest:**

1. **Highest RPM** — $12-30 YouTube Shorts, $0.40-0.80 TikTok. Finance-tier rates because advertisers pay premium for tech audience.
2. **Best affiliate commissions** — SaaS programs pay 20-50% recurring. One NordVPN signup = $10-15. AI tool referrals = $50-200/signup. Even Amazon Associates on tech accessories = 3-8%.
3. **Perfect for faceless AI-generated content** — screen recordings, product demos, text overlays, AI voiceover. No face needed. No real footage needed.
4. **Infinite content supply** — new AI tools launch weekly. Content never runs out. Each tool = 1 video.
5. **Your actual expertise** — Pipeline TD background means you understand technical tools. Taste advantage over generic content farms.
6. **TikTok Shop compatible** — tech accessories available on TikTok Shop for in-app purchase.

### Runner-up: Kitchen/Home Gadgets

Fastest to first dollar (TikTok Shop, impulse buys, no follower minimum for affiliate). Lower RPM but highest volume potential. Good second vertical after Tech is running.

### Runner-up: Finance/Money Math

Highest RPM of any niche. Strong affiliate (fintech apps). Slightly harder to produce — needs accurate numbers, compliance risk if giving financial advice.

## Recommended Vertical: Tech / AI Tools

### Content Format

```
Hook (0-3s):   "This free AI tool replaces Photoshop"
Demo (3-20s):  Screen recording of tool in action
Result (20-25s): Before/after or output showcase  
CTA (25-30s):  "Link in bio" / TikTok Shop tag
```

Variants:
- "5 AI tools you didn't know existed" (compilation)
- "$0 vs $200 — free alternative to [expensive tool]" (comparison)
- "I tested every AI video generator — here's the best" (review)
- "This AI tool just went free" (news/urgency)

### Monetization Stack (layered, fastest-first)

| Stream | When it kicks in | Est. $/month |
|--------|-----------------|-------------|
| TikTok Shop affiliate (tech accessories) | Day 1 — no follower minimum | $50-500 |
| Amazon Associates links in bio | Day 1 — instant approval | $50-200 |
| SaaS affiliate links (AI tools) | Day 1 — apply to programs | $100-1000+ |
| TikTok Creativity Program | ~Month 2-3 (need 10K followers + 100K views/30d) | $200-2000 |
| YouTube Shorts RPM | ~Month 3-6 (need 1K subs + 10M views/90d) | $100-500 |
| Sponsored integrations | ~Month 6+ (need 50K+ followers) | $500-5000 |

### Production Pipeline (current hardware — no GPU needed)

```
1. SOURCE    Claude API generates script from trending AI tool/tech topic
2. SCRIPT    Claude refines hook, demo steps, CTA
3. SCREEN    Screen record tool demo (OBS, free)
4. VOICE     ElevenLabs AI voiceover (free tier: limited, $5-22/mo)
5. EDIT      CapCut (free) — overlay text, transitions, captions
6. POST      TikTok → cross-post YouTube Shorts → Instagram Reels
7. LINK      Bio link tree → affiliate links for featured tools
```

No AI video generation needed initially. Screen recordings ARE the content. Free tools only.

### Brand Setup (Day 1)

- TikTok account → TikTok Shop affiliate signup
- Amazon Associates account
- Link tree (Linktree free tier or Beacons)

## AI Content Policy Compliance

All platforms allow AI content WITH disclosure. Rules:

1. **Label all content as AI-assisted** — use platform disclosure toggles
2. **AI voiceover is standard** in faceless niche — widely accepted
3. **Avoid "reused content" flags** on YouTube — each video must feel unique (different hooks, different structure, not template-stamped)
4. **No deepfakes of real people** — don't put words in anyone's mouth
5. **TikTok >1 minute** for Creativity Program eligibility — plan content length accordingly

### Biggest risk: YouTube "reused content" demonetization
Mitigation: Vary video structure, use different visual styles, don't batch-produce identical-feeling content. Quality over pure volume on YouTube.

## GPU Upgrade Trigger (Revisited)

With Tech/AI Tools vertical, AI video generation is **not critical at launch**. Screen recordings are the content. Free tools (Meta.ai, Vheer, CapCut) handle supplemental visuals.

GPU upgrade becomes relevant when:
- Scaling to 5+ videos/day requires AI-generated B-roll at volume
- Second vertical launched that needs AI visuals (e.g., AI art showcase)
- Monthly cloud spend on video gen exceeds $30-50/mo
