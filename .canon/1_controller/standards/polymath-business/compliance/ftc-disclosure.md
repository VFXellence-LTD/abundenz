# FTC Disclosure Requirements

Applies to Content (sponsored content, affiliate links) and Affiliate (all content). Products ecosystem exempt unless running promotions with affiliate partners.

## The rule

The FTC requires "clear and conspicuous" disclosure of material connections between an endorser and a brand. If you earn money when someone clicks a link or buys a product you recommend, you must disclose that relationship.

## Disclosure templates

### Blog post (top of article)
```
**Disclosure:** This post contains affiliate links. If you purchase through these links, I earn a commission at no extra cost to you.
```

### YouTube video description
```
Some links in this description are affiliate links. If you purchase through them, I earn a small commission. This doesn't affect my opinions — I only recommend tools I actually use.
```

### YouTube verbal disclosure
```
"Quick note: some of the tools I mention have affiliate links in the description. Doesn't cost you anything extra."
```

### Pinterest pin description
```
[Pin description text] | This pin contains affiliate links. See disclosure: [link to disclosure page]
```

### Newsletter
```
*Some links in this newsletter are affiliate links. See our [disclosure policy](link).*
```

### Standalone disclosure page (for blog/website)
```
# Affiliate Disclosure

[Brand name] participates in affiliate programs including Amazon Associates, Clickbank, and others. When you click certain links on this site and make a purchase, we may earn a commission at no additional cost to you.

We only recommend products and services we genuinely believe provide value. Our opinions are our own and are not influenced by affiliate partnerships.

For questions about our affiliate relationships, contact: [email]
```

## Rules by platform

| Platform | Requirement | Placement |
|----------|-------------|-----------|
| Blog | Disclosure before first affiliate link | Top of post |
| YouTube | Verbal + written in description | First 3 lines of description |
| Pinterest | In pin description | End of description |
| Instagram | #ad or #affiliate visible without expanding | In caption, not buried in hashtags |
| TikTok | Verbal + text overlay | Within first 3 seconds |
| Email/newsletter | Footer disclosure minimum | Bottom of email |
| Podcast | Verbal disclosure per episode | Beginning of episode |

## Common violations to avoid

- Disclosure buried below the fold or after "show more"
- Using only "#ad" with no explanation
- No disclosure on affiliate links in Instagram stories
- Affiliate links in DMs without disclosure
- Claiming "I bought this myself" when you received it free
- Incentivizing clicks ("click here to help me out!")
