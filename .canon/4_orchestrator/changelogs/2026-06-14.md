### opt-in: MC_PTY_SMOKE=1

The `server/test/pty-ws.smoke.test.ts` end-to-end PTY/WS integration test is **gated** behind the env flag `MC_PTY_SMOKE=1`. Without it the test is skipped (`1 skipped` in the suite). To run manually in PowerShell:

```powershell
$env:MC_PTY_SMOKE=1; pnpm --dir ".canon\.mission-control\server" exec vitest run test/pty-ws.smoke.test.ts; Remove-Item Env:MC_PTY_SMOKE
```

Expected: `1 passed` — echoes a marker string over the WebSocket.

### AgentRunsService.setStatus — additive change

`setStatus(id, status, error?)` gained an optional `error` string parameter. Existing 2-arg callers are unaffected (backward-compatible). The error column uses `COALESCE(?, error)` so only non-null values overwrite.
