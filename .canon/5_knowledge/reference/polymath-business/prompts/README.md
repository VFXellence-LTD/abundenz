# Shared Prompts

Prompts that are reusable across all ecosystems. Niche-specific style guides and agent prompts live in their respective ecosystem folders, not here.

## What goes here

- General formatting prompts ("rewrite this as a Twitter thread")
- Platform style packs (LinkedIn voice, X voice, Pinterest description voice) — usable by either ecosystem
- Generic utility prompts (summarization, deduplication, translation)
- The master controller prompt template

## What does NOT go here

- Signal's voice / brand style guide → `ecosystems/content/brief/style-guide.md`
- Surge's style guide → `ecosystems/viral/brief/style-guide.md` (when activated)
- Atelier's product description voice → `ecosystems/products/brief/style-guide.md` (when activated)
- Niche-specific research briefs

## Why separate

If multiple ecosystems are using the same sentence-rewrite utility, you want a single source of truth. If they're using ecosystem-specific brand voices, those must NOT be shared — that's how brand isolation breaks.
