# type beat

**Meaning/usage:** From YouTube beat-sellers tagging instrumentals "[Artist] type beat." Meme-ified to mean "a generic version of X" ("rainy Tuesday type beat"). The standalone joke is fine; the **named-artist** version is the risk.

**Three-force assessment:**
- **Trend:** Declining as a fresh meme.
- **Legal:** The phrase "type beat" is generic. **Caution: the native format pairs it with a named artist's name** ("[Drake] type beat") — using a real artist's name commercially raises publicity/TM issues. Use only the **generic/abstract** version (weather, mood, day). → `caution`.
- **Ethical:** Clean when generic; no flags. → `clean`.

**POD guidance:** Safe only as the **artist-free** version ("Monday morning type beat") with a waveform/thumbnail parody. **Never** use a real artist's name. Niche music-culture sticker. `HOLD`.
