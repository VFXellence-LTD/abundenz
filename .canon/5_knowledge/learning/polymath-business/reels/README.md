# Reels

Short-form workflow demos from Instagram, TikTok, YouTube Shorts.

These are usually <90 seconds and show a single tactic or tool in action. High signal-to-effort ratio for capture, but quality varies wildly. Be ruthless on the `What I'd steal` field — most reels are demos of obvious things.

Filename format: `YYYY-MM-DD_short-slug.md`
